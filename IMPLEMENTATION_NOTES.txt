[X] 3. FACULTY ADVISER RATING RESTRICTIONS ("Faculty dili maka rate sa iya group")
- Faculty Advisers cannot rate groups assigned to them:
  * Evaluated via `src/services/evaluationAssignment.js` (`checkEligibility`) and `src/services/evaluationService.js` (`getEligibility`):
  * A group is considered assigned to a faculty member if `user.assignedGroupIds?.includes(targetGroupId)` or `project.facultyId` matches `user.id` or `user.name` or `user.facultyId` (case-insensitive).
  * If assigned, returns `{ canEvaluate: false, code: 'assigned-team', reason: 'Faculty advisers cannot evaluate groups assigned to them.' }`.
- Faculty Advisers CAN rate other groups:
  * If non-assigned and not already evaluated, returns `{ canEvaluate: true, code: 'ok', reason: '' }`.
  * If already evaluated, returns `{ canEvaluate: false, code: 'duplicate', reason: 'You have already evaluated this group.' }`.
- UI presentation on `ProjectDetailPage.jsx`:
  * Evaluation box is visible to Faculty Advisers.
  * For their assigned groups: the "Evaluate Project" button is disabled with a lock icon, displaying the message "Faculty advisers cannot evaluate groups assigned to them."
  * For other groups: the "Evaluate Project" button is enabled, linking to `/faculty/projects/:projectId/evaluate`.
  * Added route `/faculty/projects/:projectId/evaluate` to `src/App.jsx`.
  * Updated `src/pages/student/EvaluatePage.jsx` to support faculty evaluations (navigates back to `/faculty/projects/:projectId` and on submit to `/faculty/all-projects`).
- Backend & API enforcement in `google-apps-script/Code.gs`:
  * In `action === "login"`, creates a session token for faculty (`createFacultySession`) and returns it.
  * In `action === "submitEvaluation"`, verifies evaluator using `getAuthenticatedEvaluator`.
  * If evaluator is faculty: checks if `group.Adviser` matches the faculty's `FacultyID` or `FullName`. If so, throws: "Faculty advisers cannot evaluate groups assigned to them."
  * In `action === "getEvaluationEligibility"`, returns `code: "assigned-team"` and `reason: "Faculty advisers cannot evaluate groups assigned to them."` if the group is assigned to that adviser.
